# 0.1.0验证与交付范围

更新日期：2026-10-29。公开版是可运行的手工与人工审核工作流，不代表自动采集或历史真实性已完成生产验收。

## 已验证内容

核心回归使用临时目录与构造输入，覆盖原始字段、长ID、近似热度、空输入/异常隔离、同名歧义门禁、未审核导出、旧审核失效、原文摘录存在、命题粒度支持、P0/返修限制、环境隔离、重复导出、进程恢复、证据/配置变更、篡改检测、备份恢复和基准完整范围。

HTTP测试验证本地状态与导入、CSRF、外部Host/Origin拒绝及静态安全头。浏览器曾实际验证手工线索保存和创建待查候选，并显示缺证据阻断项。

公开版新增独立模板与启动检查，测试命令：

```sh
python -m unittest discover -s tests -v
```

准确测试数量和远程平台结果以对应提交的[CI运行记录](https://github.com/CodeBlueFriend/changdeng-hotspot/actions/workflows/tests.yml)为准。本地私人工作台的集成回归不是本仓库的可复现前提。

- 合成输入下通过程序门禁测试，不等于自动理解历史语义或识别伪造史料。
- 尚无真实平台权限、抓取样本、网络重试或缓存回退验收。
- 尚无生成模型、自动实体消歧或联网证据检索执行成绩。
- 尚未建立40开发＋60锁定人工金标准；精度、召回及前三十张推荐核验为NOT_RUN。
- 已实现待立项库文件交接，尚未完成一张真实选题自动建集的生产验证。
