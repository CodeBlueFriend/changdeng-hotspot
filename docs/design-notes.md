# 界面设计决定

热点中心是历史选题的研究桌面。以左侧导航和可展开档案为主，列表保留原始标题、来源范围、两个时间和原始单位；空数据直接提供手工入口。

色彩：墨蓝 #243c48、档案蓝 #31596c、纸灰 #f4f6f7、白 #ffffff、分隔灰 #d8e1e5、核查琥珀 #8a631b。标题用系统宋体，操作和正文用系统苹方；不请求外部字体。

布局：左侧固定工作台身份及四个视图，右侧按任务显示导入表单与档案列表。小屏导航移到上方。重点放在待核查状态和来源可追溯性，不用虚构榜单或大数字仪表盘装饰空页。

设计复核：取消宣传式首屏，保留所有表单标签、键盘焦点和错误文本；实际输入经HTML转义。审核输入与作者自评分分离。
